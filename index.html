처음 시작하기

  1. 아이를 부를 별명과 나이를 입력해 프로필을 만듭니다.
  2. 홈 화면에서 오늘의 학습을 누릅니다.
  3. 짧은 문제 세트와 마지막 사고력 문제를 풉니다.
  4. 학습을 마치면 반짝별을 받고 진도와 숙련도가 저장됩니다.

인터넷 연결이나 회원가입 없이 핵심 학습 기능을 사용할 수 있습니다.

자주 묻는 질문

다른 학습 단계를 선택할 수 있나요?

나의 모험지도에서 현재 단계와 추천 단계보다 낮은 과정은 자유롭게 선택할 수 있습니다. 더 높은 과정은 짧은 단계 테스트를 통과하면 시작할 수 있습니다.

학습 도중 앱을 종료하면 기록이 사라지나요?

풀이 기록과 진행 중인 레슨은 기기에 저장됩니다. 다시 실행하면 이어서 학습할 수 있습니다.

별명은 어떻게 바꾸나요?

부모님 메뉴 → 프로필 → 아이의 별명에서 새 별명을 입력하고 별명 저장을 누릅니다. 기존 진도와 별은 유지됩니다.

프로필과 학습 기록을 삭제하고 싶어요.

부모님 메뉴 → 프로필 → 이 프로필 삭제를 누릅니다. 확인 후 해당 프로필의 진도, 별, 숙련도와 풀이 기록이 기기에서 삭제됩니다.

음성이 들리지 않아요.

  • 부모님 메뉴에서 문제와 피드백 자동으로 읽기가 켜져 있는지 확인해 주세요.
  • 기기의 음량을 높이고 다른 앱의 소리가 정상적으로 들리는지 확인해 주세요.
  • 부모님 메뉴에서 설치된 한국어 목소리를 선택하고 미리 듣기를 실행해 주세요.

효과음이 들리지 않아요.

부모님 메뉴의 정답·응원 효과음 설정과 기기의 무음 설정을 확인해 주세요.

기기를 바꾸면 학습 기록도 옮겨지나요?

현재 버전은 계정이나 자체 동기화 서버를 사용하지 않습니다. 학습 기록은 앱을 사용한 기기에 저장되므로 다른 기기로 자동 이전되지 않습니다.

학습 기록과 개인정보

별명, 나이, 학습 진도와 풀이 기록은 맞춤 학습과 복습을 위해 사용 중인 기기에만 저장됩니다. 광고 및 분석 SDK를 사용하지 않으며 개발자 서버로 전송하지 않습니다.
